using avr-gcc and AVRDUDESS

Install avr-gcc compiler.[1]
- Download and extract relevant file (avr8-gnu-toolchain-3.7.0.1796-win32.any.x86_64.zip) from [2].
- Add bin folder to path variable.
- OR use a .bat file that adds it to path just for a cmd session[6].
- OR just use bin folder as current working directory in cmd later.  <<<


Install AVRDUDESS (gui for avrdude).[1]
- Download and run relevant file (AVRDUDESS-2.18-setup.exe) from [7].
- OR, download and extract the portable zip.  <<<


Compile example blink program.[1][8]
blink.c:
#define F_CPU 1000000UL

#include <avr/io.h>
#include <util/delay.h>

int main(void) {
	DDRB |= (1 << PB0);

	while (1) {
		PORTB |= (1 << PB0);
		_delay_ms(2000);
		PORTB &= ~(1 << PB0);
		_delay_ms(2000);
	}

	return 0;
}

- run in cmd:
avr-gcc -mmcu=atmega8535 -Wall -Os -o blink.elf blink.c

-mmcu option selects microcontroller;[3] pg103, [4]
-Os optimizes for size;[3] pg110, [5]
-[3] pg49 links to gcc user manual[9]
-Wall enables all warnings[10]
-o is followed by name of output file; blink.c is input file[11]


Plug in USBasp programmer. Windows autoinstalls a driver.

Change driver.
- Run zadig-2.4.exe [6][12] (from [13] or [15]) (no install, just runs).
- Select USBasp and libusb-win32. [12]

Connect USBasp to microcontroller.[1], [14] pg251

Load program with AVRDUDESS.[12]
- Run avrdudess.exe .
- Select programmer: usbasp , select microcontroller: ATMega8535, select blink.elf file.
- Click Program! button.
